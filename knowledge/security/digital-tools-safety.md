# Ringkasan Materi & Fakta Utama:
Banyak pengguna mengira bahaya software bajakan cuma sekadar 'kena virus yang bikin lemot'. Di tahun 2026, ancaman utamanya adalah **Infostealer Malware** yang menyasar token autentikasi browser.

## Cara Kerja Infostealer:
1. File `.exe` atau patch aktivator disisipi payload stealth.
2. Malware mengekstrak file `Cookies.sqlite` dan session token sosmed yang tersimpan di Google Chrome / Edge.
3. Penyerang meng-inject cookie tersebut ke browser mereka sendiri, membobol akun tanpa butuh password atau 2FA OTP.
4. Korban baru sadar saat akun Instagram/LinkedIn/crypto mereka tiba-tiba memposting spam pinjaman online.

## Langkah Proteksi Nyata:
- Hindari menjalankan file patching berformat `.bat` atau `.exe` yang meminta disable antivirus.
- Rutin bersihkan session cookie aktif di browser minimal sebulan sekali.
