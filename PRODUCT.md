# PRODUCT.md: Threads Marketing & AI Draft Manager

## 1. Product Identity & Purpose
- **Product Name**: Threads Marketing Hub & AI Draft Manager
- **Domain**: Digital Goods & Subscription Commerce (YouTube Premium, Spotify, Netflix, Canva, etc.)
- **Primary Goal**: Empower digital product sellers to orchestrate high-converting marketing campaigns on Threads with strict AI draft review, multi-part thread editing, real-time 500-char verification, authentic Threads preview, and automated Hermes Agent cron integration.
- **Audience**: Digital product store owners, social media marketing managers, solopreneurs.

## 2. Core Surface Mode
- **Mode**: `Operate` (App UI / Dashboard / Multi-part Content Editor / Real-time Threads Simulator).
- **Key UX Priorities**:
  1. **Frictionless Review & Edit**: Instant visibility of pending drafts generated by AI.
  2. **Authentic Threads Fidelity**: Live preview must render exactly how Threads looks (avatar, username, connecting thread line, action bar, typography, spacing, 500-char limits).
  3. **Rich Context Management**: Clear structured product catalogs (variants, pricing, USPs, target audience, tone of voice, CTAs).
  4. **Transparent Hermes Agent Status**: Real-time status indicators for Hermes API connectivity and cron post executions.
